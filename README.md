# STUDYNE - Learning Management System

STUDYNE adalah prototype Learning Management System (LMS) berbasis web untuk mendukung pembelajaran mahasiswa dan dosen.

## Fitur
- Landing page: deskripsi aplikasi, informasi mata kuliah, fitur utama, login/register, footer.
- Registrasi dan login untuk Mahasiswa dan Dosen.
- Lupa password melalui pemulihan akun pada localStorage.
- Dashboard Mahasiswa: mata kuliah, progress, jadwal, tugas mendatang sebagai pemberitahuan, dan notifikasi.
- Dashboard Dosen: mata kuliah, mahasiswa terdaftar, tugas, serta informasi pengumpulan.
- Halaman Mata Kuliah: materi dan tugas.
- Detail tugas: instruksi, deadline, upload file, status pengumpulan, kirim ulang sebelum deadline.
- Responsif untuk desktop dan mobile.

## Teknologi
HTML5, CSS3, JavaScript, SVG, localStorage.

## Menjalankan
Buka terminal:
```powershell
cd C:\STUDYNE-LMS
start .\index.html
```

## Catatan
Aplikasi menggunakan localStorage sehingga cocok untuk demo/prototype. Untuk deployment multi-pengguna diperlukan backend dan database.
